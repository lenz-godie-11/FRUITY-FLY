For readers interested in the implementation:

- **Graph construction:** The 16,000-neuron subset retains the earlier 8,000 neurons, grows by measured connectivity with a preference for central-complex neurons, and keeps measured edges between selected neurons while omitting self-connections. All 16,000 lie on input-to-output paths, and the graph is one strongly connected component. This is an engineered subset, not an intact biological circuit.
- **Weights and dynamics:** Initial edge magnitudes are synaptic-contact counts normalized by the target neuron's retained incoming contacts. Predicted GABA/glutamate sources are assigned negative signs and other/unknown sources positive signs—a simplifying assumption without receptor-specific dynamics. Each edge has a bounded positive gain. Three leaky tanh updates process each decision; this is a rate model, not a simulation of individual spikes or 27 million separate synapse dynamics.
- **Inputs and memory:** There are 110 observation features. The home bank is written at departure; visited-place memory accumulates learned encodings using an elementwise maximum. Both banks have 100 state slots with designed persistence gates. Transient processing resets each decision. The policy receives neither the remote beacon coordinates nor the base coordinates after departure. It assumes a known obstacle map and ideal localization. Input and memory signals reach action readouts through the measured graph, without a direct bypass.
- **Learning:** 4,096 initial teacher layouts plus three rounds of 384 policy-generated layouts: 5,248 training layouts. The teacher uses map and history and learns the beacon location through the local sensor. Adam uses a 0.001 learning rate and batch size 128. The loss combines action cross-entropy, home-cell cross-entropy (weight 0.15), and visited-cell binary cross-entropy (weight 0.10). Graph gains are frozen for the first 400 updates. There are 3,200 initial updates plus three rounds of 1,200. Recovery rounds restart from the best development weights and optimizer while retaining the expanded history pool. No teacher or route planner supplies deployed policy actions.
- **Selection and evaluation:** The checkpoint at update 6,400 was selected on 64 development layouts. Final evaluation used 128 separate unseen layouts. The selected checkpoint changed 2,353,476 connection gains from initialization. There were 32 failures before pickup and 57 after pickup. Successful missions averaged 37.5 moves.
- **Memory controls:** Clearing neural memory each decision reduced complete returns from 39 to 10; clearing visited-place memory reduced them to 9; silencing neural activity produced 0. Erasing only home memory after pickup reduced returns from 39 to 36, so robust dependence on that particular bank is not established. The reference explorer completed 128/128 missions. These results do not establish an advantage over equally trained conventional or rewired networks.
- **Compute:** The dense 16,000×16,000 float32 recurrent matrix occupies 1.024 GB before gradients and optimizer allocations. MPS driver allocation at the end of training was about 4.22 GB; peak memory was not measured. The roughly 26.5-minute training-loop time includes development evaluations and recovery rounds but excludes initial demonstration generation.
- **Visualization:** The selected replay is seed 200089: pickup after move 35, return after move 42. The 40-second, 1080p animation preserves the recorded horizontal route and holds each neural state for its corresponding decision. Cyan/amber indicate positive/negative simulated signed activity on a fixed brightness scale. The transparent shell is an envelope of measured soma positions, not a segmented anatomical surface. Flight physics and camera perception are outside this experiment.
